# 💻 100+ JavaScript Problem Solving Challenges

A collection of **100+ JavaScript coding challenges** designed for beginners to improve their problem-solving skills, strengthen their JavaScript fundamentals, and build logical thinking step by step.

## 🎯 About This Repository

This repository contains practical JavaScript problems, starting from basic concepts and gradually moving toward more challenging problems.

The main goal is to practice JavaScript, understand programming logic, and develop strong problem-solving skills through consistent practice.

## 📚 Topics Covered

The problems are organized into different topics:

| # | Topic | Description |
|---|---|---|
| 01 | Variables & Data Types | Variables, strings, numbers, and booleans |
| 02 | Operators | Arithmetic, comparison, and logical operators |
| 03 | Conditional Statements | if, else, else if, and switch |
| 04 | Loops | for, while, and do...while |
| 05 | Functions | Function declarations, expressions, and arrow functions |
| 06 | Arrays | Array methods and manipulation |
| 07 | Strings | String methods and manipulation |
| 08 | Objects | Object properties and methods |
| 09 | Math & Numbers | Mathematical operations and number problems |
| 10 | Advanced Basics | Scope, callbacks, recursion, and more |
